## 🚀 Featured Projects

### 1. FMCG Retail Data Engineering Pipeline
**Tech:** Databricks, PySpark, Delta Lake, AWS S3, Unity Catalog, GitHub Actions

An end-to-end batch pipeline that ingests FMCG retail data from AWS S3 into a Databricks lakehouse using Medallion Architecture.

- Organised data into Bronze, Silver, and Gold layers.
- Cleaned, typed, deduplicated, and transformed customer, product, pricing, and order data.
- Used Delta Lake `MERGE` operations for idempotent full and incremental loads.
- Built fact tables and monthly aggregate data for analytics.
- Configured a GitHub Actions workflow to trigger the Databricks pipeline.

[View FMCG Pipeline Repository](https://github.com/izharamna238-dev/fmcg_pipeline)

### 2. Workflow Orchestration with Apache Airflow 3
**Tech:** Apache Airflow, Python, Docker Compose, Celery, PostgreSQL, Redis

A containerised Airflow learning and workflow project focused on orchestration concepts and practical DAG development.

- Set up a local Airflow environment using Docker Compose.
- Practised TaskFlow API, Bash operators, XComs, parallel execution, and branching.
- Explored scheduling with cron expressions, presets, and time-based intervals.
- Practised incremental loading and asset-based scheduling.
- Orchestrated parent–child DAG workflows.

[View Airflow Project Repository](https://github.com/izharamna238-dev/Airflow_Project)

### 3. End-to-End Data Pipeline – Medallion Architecture
**Tech:** AWS S3, Snowflake, dbt, Python, Git

A data warehouse pipeline designed around a Bronze–Silver–Gold architecture.

- Loaded raw files from AWS S3 into Snowflake using an external stage secured with AWS IAM.
- Developed dbt models, sources, custom schemas, Jinja functions, and reusable macros.
- Worked with incremental loading and upsert logic.
- Applied dbt data tests to validate data quality.
- Modelled analytical data using a Star Schema and tracked historical changes with dbt snapshots (SCD Type 2).
